# Quick Deployment Prompt - Railway Template

Use this prompt when explaining to Claude/ChatGPT or another AI how to deploy your app:

---

**PRODUCTION DEPLOYMENT PROJECT - RAILWAYS PLATFORM**

I have a full-stack business management app that needs to be deployed on Railways:

**Architecture:**
- Backend: Flask (Python) REST API that uses MySQL database. App runs via Gunicorn on port 8000
- Frontend: React + TypeScript + Vite app that calls the backend API
- Database: MySQL with multi-branch support, POS, inventory, procurement, analytics

**Backend Details:**
- Language: Python Flask
- Modules: user authentication, inventory, POS, procurement, branches, dashboard, analytics
- Database: MySQL (DB_HOST, DB_USER, DB_PASSWORD, DB_NAME, DB_PORT via env vars)
- Authentication: JWT with bcrypt hashing (JWT_SECRET env var needed)
- Start command: `gunicorn --bind 0.0.0.0:$PORT app:app --workers 2 --timeout 120`
- Procfile: `web: gunicorn app:app`
- Database schema located at: `backend/src/knopper_database_v1 (1).sql`

**Frontend Details:**
- Language: React + TypeScript
- Build tool: Vite
- Entry point: `frontend/src/main.tsx`
- Build command: `npm install && npm run build` (outputs to `frontend/dist/`)
- Server: Static files (need to serve `frontend/dist/` directory)
- API communication: Calls backend at `/api/*` endpoints via fetch

**Deployment Steps:**
1. Create MySQL service on Railways, import database schema
2. Create Python service for backend:
   - Set ROOT_DIR to `backend/`
   - Add env vars: DB_HOST, DB_USER, DB_PASSWORD, DB_NAME, DB_PORT, JWT_SECRET
   - Start command: `gunicorn --bind 0.0.0.0:$PORT app:app --workers 2 --timeout 120`
3. Create Node.js service for frontend:
   - Build: `cd frontend && npm install && npm run build`
   - Serve: `npm install -g http-server && http-server frontend/dist -p $PORT`
   - Add env var: VITE_API_BASE_URL=<backend-url>

**Repository Structure:**
- `/backend/` - Flask app with all modules
- `/frontend/` - React + TypeScript Vite app
- `backend/requirements.txt` - Python dependencies
- `frontend/package.json` - Node dependencies
- `backend/src/knopper_database_v1 (1).sql` - Database schema to import

**User Roles:**
- Admin: Full system access (all modules)
- Manager: Branch-level management
- POS Cashier: Point of Sale operations only

Can you help me deploy this to Railways step-by-step?
